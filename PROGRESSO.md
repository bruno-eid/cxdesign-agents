## 🎯 Como Usar o Sistema

### 1. Onboarding Rápido (5 minutos)
```bash
1. Leia GETTING-STARTED.md
2. Navegue pelo INDEX.md
3. Escolha um template
4. Comece seu projeto
```

### 2. Criar Novo Projeto
```bash
1. Copie projetos/_template/
2. Renomeie para seu projeto
3. Use os templates das fases
4. Documente o progresso
```

### 3. Seguir o Fluxo
```
Fase 0 → Gateway 1 → Fase 1 → Gateway 2 → 
Fase 2 → Gateway 3 → Fase 3 → Gateway 4 → 
Fase 4 → Gateway 5 → Entrega
```

### 4. Validar Qualidade
```bash
1. Use os checklists de cada fase
2. Valide nos Gateways
3. Documente decisões
4. Aprenda com o CX Brain
```
