## 🎯 Casos de Uso Documentados

### 1. App Mobile de Fitness
**Cenário:** Designer precisa criar interface de um app de fitness do zero

**Fluxo Completo:**
1. Briefing inicial com objetivos e restrições
2. Fase 0: Definição de escopo e viabilidade
3. Fase 1: Pesquisa de mercado e criação de personas
4. Fase 2: Arquitetura de informação e wireframes
5. Fase 3: Design system e protótipos de alta fidelidade
6. Fase 4: Validação de acessibilidade e handoff

**Tempo Estimado:** 4-6 semanas
**Iterações:** 2-3

### 2. Redesign de Sistema Legado
**Cenário:** Modernização de interface legada mantendo funcionalidades

**Desafios:**
- Análise de sistema existente
- Identificação de problemas de usabilidade
- Migração gradual de componentes
- Manutenção de compatibilidade

**Tempo Estimado:** 8-12 semanas
**Iterações:** 3-5

### 3. Exploração Criativa
**Cenário:** Designer busca inspiração para novo conceito

**Características:**
- Brief criativo aberto
- Múltiplas direções exploradas
- Foco em inovação
- Aprendizado de preferências

**Tempo Estimado:** 2-3 semanas
**Iterações:** 4-6

## 🎨 Exemplo: App Mobile de Fitness

### Briefing Inicial

```markdown
# Briefing: FitLife App

## Contexto
Startup de fitness quer criar app mobile para acompanhamento de treinos.

## Objetivos
- Facilitar registro de treinos
- Motivar usuários com gamificação
- Integrar com wearables
- Comunidade de usuários

## Público-Alvo
- Idade: 25-45 anos
- Perfil: Praticantes regulares de exercícios
- Comportamento: Tech-savvy, orientados a dados

## Restrições
- Orçamento: R$ 150k
- Prazo: 3 meses
- Plataformas: iOS e Android
- Tecnologia: React Native

## Concorrentes
- Nike Training Club
- Strava
- MyFitnessPal
```

### Fase 0: Output do Estrategista

```markdown
# Contrato de Escopo Técnico - FitLife

## Viabilidade: ✅ APROVADO

### Matriz de Maturidade
- Design: Nível 2 (Emergente)
- Técnica: Nível 3 (Arquitetura Moderna)
- UX: Nível 2 (Pesquisa básica)

### Restrições Mapeadas
1. **Técnicas:**
   - React Native (iOS + Android)
   - Integração com HealthKit/Google Fit
   - Backend: Node.js + PostgreSQL

2. **Negócio:**
   - Budget: R$ 150k
   - Timeline: 12 semanas
   - MVP primeiro, features avançadas depois

### Fora do Escopo (V1)
- Planos de treino personalizados por IA
- Marketplace de personal trainers
- Streaming de aulas ao vivo

### Próximos Passos
→ Fase 1: Pesquisa de usuários e análise competitiva
```

### Fase 1: Output do Pesquisador

```markdown
# Insights de Pesquisa - FitLife

## Personas Criadas

### Persona 1: "Ana Consistente"
- 32 anos, analista de sistemas
- Treina 4x/semana há 2 anos
- **Dor:** Dificuldade em acompanhar progresso
- **Ganho:** Visualização clara de evolução

### Persona 2: "Carlos Iniciante"
- 28 anos, designer
- Começou a treinar recentemente
- **Dor:** Não sabe se está fazendo certo
- **Ganho:** Orientação e motivação

## Matriz de Fricções

| Fricção | Severidade | Oportunidade |
|---------|------------|--------------|
| Registro manual demorado | Alta | Auto-detecção de exercícios |
| Falta de feedback imediato | Média | Notificações motivacionais |
| Dificuldade em manter rotina | Alta | Gamificação e streaks |

## Jornada As-Is
[Mapeamento da jornada atual com pain points]

### Próximos Passos
→ Fase 2: Arquitetura de experiência
```
