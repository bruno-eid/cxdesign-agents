### Fluxo Principal

```
Q1 (Consentimento)
    ↓ Sim
Q2-Q5 (Perfil)
    ↓
Q6-Q14 (Seção Principal)
    ↓
Q15-Q17 (Feedback)
    ↓
Agradecimento
```

### Ramificações

**Ramificação 1:**
```
Q7 = "Opção 1" → Pular para Q10
Q7 ≠ "Opção 1" → Continuar para Q8

**Ramificação 2:**
```
Q13 = 0-6 → Mostrar Q14a (Detratores)

```

```
